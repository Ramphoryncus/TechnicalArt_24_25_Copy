# Documentation

Developed with Unreal Engine 5

## Tools and Applications used during this project

### JetBrains Rider

I used the JetBrains Rider IDE for some C++ coding. I attempted to implement a custom gravity system so my character would be able to run around on the inside wall of the giant lightning bowl. I sourced a custom gravity system from the dev.epicgame.com documentation, but this failed to produce the desired results, some tweaking would probably have got me close to what I was hoping for, but in the end I disabled it. I also attempted to make a custom gravity system using Rider with the assistance of chat GPT 4o. This did not produce any results as there were some errors within the player controller C++ class that could not be fixed by me at the time.

### AutoDesk Maya 3D Modelling Application

I use the Autodesk Maya 3D modelling application to create all of my assets except the standard cubes that you get In Unreal Engine 5.4.4. The only model that I did not create from scratch was the player character, Charger, for that character mesh I used a default human mesh that you can find in Maya and made some alterations, handcrafted goggles, mask and the raised metal strips on Charger’s suit.

### Adobe Substance Painter

I textured all of my 3D meshes in Substance Painter, except the activatable pillar for which I assigned materials in Unreal Engine 5. Each mesh has a layered material and I utilised masking and polygon fills to speed up the process. I did some hand texturing on the tenderiser and on the gyroscopic portal, in particular the emissive dots on each of the rings.

### ChatGPT 4o

I did seek assistance from Chat-GPT 4o on an ongoing basis to help me troubleshoot any issues that I was having with blueprints and also attempted to code a custom gravity system from scratch in C++ before reverting to the custom gravity system on the dev.epicgames.com page, that did work just not how I wanted it to it may have needed some tweaking 

### Mixamo

I use the Mixamo website to source all of the animations for my player character
